# 账号与设备

## 创建账号

应用会在你的设备上生成根密钥，并显示你的**恢复包**：账号 ID 和恢复密钥写在同一段文字里。恢复密钥不会保存在任何地方，只显示这一次：请保存好恢复包（复制、分享到密码管理器，或存成文件）。应用会让你输入恢复密钥的最后四位，确认你已经保存。

别人通过账号 ID 找到你：给对方看你的二维码，或者把 ID 发给对方。gim 没有用户名：Hub 由各自的运营者部署，同一个名字在不同 Hub 上可能属于不同的人。

## 关联新设备

关联需要一台已经登录的设备。

1. 在新设备上选择关联到已有账号，它会显示一个二维码。
2. 用已登录的设备扫描这个二维码。
3. 两台设备都会显示一个六位数字。确认两者一致，然后在**两台**设备上都点确认。

之后新设备会加入你的聊天。关联请求 10 分钟后失效，失效后重新开始即可。如果数字不一致，请拒绝：新设备会被移除。

## 所有设备都丢失后恢复

在新设备上选择恢复，粘贴你的恢复包（任何语言都可以，应用会从文字里找出账号 ID 和密钥）。可以同时移除旧设备，被移除的设备无法再登录。

如果之前开着 Keep 服务器，屏蔽名单和隐私设置会从那里恢复（[服务器](../servers/overview.md)）。聊天不会自动重新加入：需要其他成员或你的其他设备把恢复后的设备重新加进来。

## 生成新的恢复密钥

如果恢复密钥丢了，而还有设备处于登录状态，可以在应用设置里生成新的恢复密钥。旧密钥随即失效。

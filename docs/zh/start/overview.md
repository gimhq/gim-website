# gim 是什么

gim 是端到端加密的即时通讯。目前有 Android 和 macOS 应用，以及一个用于脚本和测试的命令行客户端（[安装](install.md)）。

## 在你的设备上加密

聊天使用 MLS（RFC 9420）。消息、图片和文件在发送方设备上加密，只有聊天成员能解密。每个媒体文件都有自己的随机密钥，这个密钥放在加密消息里传递，从不交给服务器。

## 账号就是密钥

创建账号时，设备上会生成一把根密钥，账号 ID 由它派生。不需要手机号，也不需要邮箱，也没有用户名：别人通过账号 ID 找到你。即使所有设备都丢了，也能用恢复包找回账号（[账号与设备](account.md)）。

## Hub 只投递，不读取

Hub 是在设备之间传递消息的服务器，它保存密文，直到你的设备取走。一个账号可以同时使用多个 Hub；互相联邦的 Hub，其用户之间也能聊天。Keep 服务器只保存隐私设置的加密备份，以及你主动提交的举报（[服务器](../servers/overview.md)）。
